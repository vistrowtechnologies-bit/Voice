---
title: "Knowledge Base"
description: "Ground your agent's answers in your own documents instead of letting it improvise."
---

A knowledge base is a set of question–answer pairs an agent retrieves from during a call, so pricing, policies, and product details come from material you approved — not the model's best guess.

## Adding content

1. Go to **Knowledge Base** and either create a new one or open an existing one.
2. Upload a brochure, price sheet, or any document, and click **Auto-extract Q&A**. Vistrow Voice reads the file and generates clean question–answer pairs from it.
3. Review every generated answer and edit any of them inline — auto-extraction is a starting point, not the final word.

Each knowledge base has a character budget (shown as a usage bar, e.g. `4.0k / 8k characters used`) across all its Q&A pairs combined.

## Strict mode

With **Strict mode** on, the agent only quotes these approved answers instead of improvising when a caller asks something outside them. Turn it off if you'd rather the agent use its general knowledge as a fallback for anything not covered.

## Attaching to an agent

A knowledge base isn't used automatically — attach it to a specific agent from that agent's settings (see [Agents](/platform/agents)). Different agents can point at different knowledge bases, so a sales agent and a support agent can each answer from their own material.
