Vistrow Voice runs on a credit system: **1 credit ≈ 1 minute** of call time, at a rate that depends on the call's channel and voice tier.

## Usage by call type

| Channel | Rate |
|---|---|
| Dashboard browser calls | 1 credit/min |
| Website widget calls | 1 credit/min |
| Real phone calls | 1.5 credits/min |

Phone calls burn more credits per minute than browser or widget calls because they carry a telephony cost the others don't.

## Usage by voice tier

| Tier | Rate |
|---|---|
| Economy | 0.5× credits |
| Standard | 1× credits |
| Premium | 2× credits |

Premium voices cost more to run, but sound more expressive and react live to the caller's emotion — pick per agent based on what the use case actually needs.
