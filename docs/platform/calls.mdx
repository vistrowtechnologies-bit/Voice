Every call — phone, website widget, or browser test — lands in one call history, filterable by channel.

## Call list

Filter by **All / Web / Website Widget / Phone**, search by caller name or number, or filter by feedback. Each row shows status, channel, website (for widget calls), duration, recording availability, sentiment, and which agent handled it.

## Call detail

Opening a call shows:

- **Call transcript** — the full turn-by-turn conversation, downloadable as text.
- **Conversation intelligence** — click **Analyze** to run AI analysis and get a summary, sentiment, outcome, QA score, and next steps for that specific call.
- **Recording** — inline playback and MP3 download, if recording is enabled in [Compliance](/platform/compliance) for your account.

## Feedback

Mark a conversation helpful or not — conversations marked **not helpful** surface on the dashboard's "Needs attention" panel so your team can review them.
