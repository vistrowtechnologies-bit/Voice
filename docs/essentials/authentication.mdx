The dashboard itself authenticates with a session cookie, but any request can also authenticate with an **API key** — the same way, whether you're calling from a script, a backend service, or an integration.

## Generate a key

<Note>
  API keys are part of the **Scale** plan, and only workspace **admins** and the **owner** can create or revoke them.
</Note>

<Steps>
  <Step title="Open API keys">
    Sign in to the dashboard and go to **Settings → Developer → API keys**.
  </Step>
  <Step title="Name the key and pick its permissions">
    Give it a name that says where it'll be used (e.g. `production-backend`) and tick the permissions it needs. New keys start with **Read** and **Calls** ticked.
  </Step>
  <Step title="Create and copy it">
    Click **Create key** and copy it straight away — it's shown once and never again.
  </Step>
</Steps>

## Permissions

| Permission | What the key can do |
|---|---|
| **Read** | View calls, agents, contacts, campaigns and appointments. |
| **Calls** | Start calls, run campaigns, add contacts and book appointments. |
| **Agents** | Create and change agents and knowledge bases. |
| **Full** | Everything above. |

Even a **Full** key can never reach billing, your team, your profile, sign-in, or other API keys. Those stay in the dashboard.

<Warning>
  Treat a key like a password. Use a separate key for each system, give it only the permissions it needs, and click **Revoke** on any key you no longer use or think was exposed.
</Warning>

## Authenticate a request

Send the key in the `X-Api-Key` header on every request. No other header or query parameter is needed.

<CodeGroup>

```bash cURL
curl https://app.vistrowvoice.com/api/agents \
  -H "X-Api-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch("https://app.vistrowvoice.com/api/agents", {
  headers: { "X-Api-Key": process.env.VISTROW_API_KEY },
});
const agents = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://app.vistrowvoice.com/api/agents",
    headers={"X-Api-Key": "YOUR_API_KEY"},
)
agents = res.json()
```

</CodeGroup>

## Scope

A key belongs to the workspace that created it. Every request made with it sees only that workspace's data, limited to the permissions you gave the key — nothing from any other account.
