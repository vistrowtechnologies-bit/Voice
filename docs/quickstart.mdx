<Tip>
  **Fastest start: Build with AI.** Go to **Agents → New Agent → Build with AI**, describe your business, and it drafts the whole agent — prompt, voice, welcome message and more — for you to review. See [Build with AI](/platform/build-with-ai).
</Tip>

<Steps>
  <Step title="Create your agent">
    In the dashboard, go to **Agents → New Agent**. Choose **Build with AI** to have it drafted for you, or **Start from scratch** to fill in every setting yourself: a name, a voice, a default language, and the persona — who it is, what business it represents, and what it should try to achieve on a call.

    The first live agent on your account automatically takes all web calls, so create it before wiring up a phone number or widget.
  </Step>
  <Step title="Add your knowledge">
    Go to **Knowledge Base**, upload a PDF or paste in text, and hit **Auto-extract Q&A**. Vistrow Voice turns it into clean question-answer pairs your agent retrieves from at call time.

    Turn on **Strict mode** if the agent should only ever answer from this material instead of improvising.
  </Step>
  <Step title="Test it">
    On the **Agents** page, each agent card has two test buttons:
    - **Browser test** (the mic button) — talk to the agent in your browser.
    - **Call test** (the phone button) — get a real phone call from the agent.

    You're talking to the exact same prompt, voice, and knowledge base it will use on a real call. For repeatable test scenarios, use the [Testing Lab](/platform/testing-lab).
  </Step>
  <Step title="Connect a channel">
    Pick how callers actually reach it:
    - **Phone number** — go to **Phone Numbers**, connect a provider, and route the number to your agent.
    - **Website widget** — go to **Website Widget**, add your site, and paste one script tag before `</body>`.
  </Step>
  <Step title="Check your calling rules">
    Before you dial anyone, open **Settings → Calling rules** and confirm the calling window (TRAI limits unsolicited calls to 9am–9pm, Mon–Sat by default), Do-Not-Call registry, and consent settings match how you plan to use the platform.
  </Step>
</Steps>
