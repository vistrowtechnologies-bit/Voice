title: "Agents"

---

## List agents

<CodeGroup>

```bash cURL
curl https://app.vistrowvoice.com/api/agents \
  -H "X-Api-Key: YOUR_API_KEY"
```

</CodeGroup>

`GET /agents` — returns every agent on your account as a JSON array.

Each agent has two IDs:

| Field | What it is |
|---|---|
| `id` | The internal numeric ID. Use this in API paths such as `PATCH /agents/{agentId}`. |
| `publicId` | The 10-digit **Agent ID** shown on the agent's dashboard page. It's the `agent_id` sent with every lead to ArthaLeads and your webhooks — use it to match leads to agents in other tools. |

## Create an agent

<CodeGroup>

```bash cURL
curl -X POST https://app.vistrowvoice.com/api/agents \
  -H "X-Api-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Sales Agent",
    "description": "Qualifies inbound leads",
    "model": "sarvam/sarvam-105b-conversations",
    "voice": "google:chirp3:Achernar",
    "language": "hi-IN",
    "systemPrompt": "You are a helpful sales assistant for Acme Corp."
  }'
```

</CodeGroup>

`POST /agents`

| Field | Type | Default | Notes |
|---|---|---|---|
| `name` | string | `"Unnamed agent"` | |
| `description` | string | `""` | |
| `model` | string | `"sarvam/sarvam-105b-conversations"` | **Vistrow Bharat**, the model offered in the dashboard. |
| `voice` | string | `"google:chirp3:Achernar"` | Myra HD. Must be a catalog voice your plan includes; preview voices are rejected. |
| `language` | string | `"hi-IN"` | Default reply language before any switching. |
| `systemPrompt` | string | `""` | Leave blank for the built-in generic assistant prompt. |

## Update an agent

<CodeGroup>

```bash cURL
curl -X PATCH https://app.vistrowvoice.com/api/agents/AGENT_ID \
  -H "X-Api-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "Renamed Agent"}'
```

</CodeGroup>

`PATCH /agents/{agentId}` — `agentId` is the numeric `id`, not the 10-digit `publicId`. Send only the fields you want to change. Returns `404` if the agent doesn't exist on your account.

## Delete an agent

```bash
curl -X DELETE https://app.vistrowvoice.com/api/agents/AGENT_ID \
  -H "X-Api-Key: YOUR_API_KEY"
```

`DELETE /agents/{agentId}` — again, the numeric `id`.
